Delete Your Yalla Match Account

If you would like to delete your Yalla Match account, follow the instructions below or contact our support team for assistance.

Some deletion details still need owner confirmation

The in-app steps below are confirmed in the app code. Retention, any data that remains, and the time needed to process an email request are not stated in the app, so this page does not invent those numbers.

Delete the account in the app

  1. Open Yalla Match and sign in with Google. Guest mode does not show account deletion because there is no account.
  2. Open the Profile tab.
  3. Tap Settings.
  4. Under Account, tap Delete Account.
  5. A dialog titled “Delete Account?” says: “This action cannot be undone. Your profile, matches, and data will be permanently deleted.”
  6. Tap Delete Account to confirm. The app sends a deletion request to the Yalla Match service. On success it signs you out, revokes the Google session used by the app, and shows “Account deleted successfully”.

How is a request verified?

In-app deletion happens while you are signed in, so the request is tied to that account session. An email does not delete the account at the moment you send it. Support still has to confirm the account holder without asking for a password or a one-time code.

What does the app say is deleted?

The dialog says the profile, matches, and data will be permanently deleted. The service response can include a message and a deletion time. The app code does not list which server records, backups, notification tokens, or reports the server removes.

What might be retained?

The privacy draft dated 12 August 2026 says in-app deletion removes or anonymizes account data on active systems, except what must be kept for legal, security, or fraud-prevention reasons, and that copies may remain in backups for a period that is not given as a number of days. The app code does not prove that server behavior, so this page states no day count.

If you cannot delete it in the app

You can send an email request. Include the Google account email you use in the app. Do not send a password or a verification code.
